# Chinese-Latin

生物（以昆虫为主）**学名 ↔ 中文名**对照数据。以 GBIF backbone（Taxon.tsv，7,746,724 行 / 5,917,391 个唯一学名）为骨架，按 **自建昆虫库 > SP2000 > iNaturalist** 的优先级补齐中文名，同一行只填空缺、不覆盖已有中文。

## 数据概况

- backbone 总行数 **7,746,724**，唯一学名 **5,917,391**
- 补到中文 **1,378,153 行（17.79%）**，唯一学名 **1,208,467（20.42%）**
- 合并耗时 143 s

需要「干净版本」可过滤 `中文来源 NOT LIKE 'Y002%'`。

## 已知局限

1. 中文名集中在中国区系，北美 / 非洲 / 南美本地种基本无约定俗成中文名——属正常空缺，非漏抓。
2. SP2000 目前仅 2023 版（GBIF 上 2024–2026 archive 均 404）。
3. iNat 中文名偏台湾用语（如「薔薇」），若 SP2000 有大陆通用名则优先 SP2000。
4. 未定阶元（unranked，127.6 万行）几乎无中文，覆盖率仅 0.3%。

## 许可

中文名数据分别来自《中国生物物种名录》（SP2000）与 iNaturalist，请遵循各自原始许可（iNat 观察与分类数据为 CC BY-NC 等条款）。本项目仅做合并与对照整理。
